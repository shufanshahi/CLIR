## Step-by-Step Setup

### Step 1: Install Required Packages

```bash

```

**Note:** The system works without `googletrans` using named entity mapping.

### Step 2: Verify Scraped Data

Check that you have articles in JSON format:

```bash

ls Module_A/Bangla_DB/DhakaPost/articles.json
ls Module_A/Bangla_DB/ProthomAlo/articles.json
```

Each `articles.json` should contain an array of objects with:
- `title`: Article title
- `body`: Article content

- `date`: Publication date
- `language`: 'bn' or 'en'

### Step 3: Build the Document Index (Module A Completion)

This is the **INDEXING** requirement for Module A:

```bash

python indexer.py
```

**What this does:**
1. Reads all articles from JSON files
2. Creates inverted index (term → documents mapping)
3. Calculates TF-IDF and BM25 scores
4. Saves index to `document_index.pkl`

**Expected output:**
```

Total documents: 2500
Vocabulary size: 50000
Average document length: 450.23

=== Index Statistics ===
Bangla documents: 1800
English documents: 700

Index saved to document_index.pkl
```

**Understanding Indexing:**
- **Inverted Index**: Maps each word to documents containing it
- **Purpose**: Enables fast document retrieval during search
- **Like**: Index at the back of a textbook
- See `Module_A/README.md` for detailed explanation

## Module B Complete Implementation

### What is Implemented:

#### 1. Language Detection ✅
- Automatically detects Bangla vs English
- Based on Unicode character ranges
- Works for mixed language queries

#### 2. Normalization ✅
- Lowercase conversion (English)
- Whitespace removal
- Optional stopword removal
- Preserves Bangla script

#### 3. Query Translation ✅
**Two modes:**

**a) Simple Translation (No external API needed):**
- Named entity mapping (Bangladesh → বাংলাদেশ)
- Works offline
- Fast and reliable

**b) API Translation (Optional):**
- Uses Google Translate API
- Better translation quality
- Requires `googletrans` package
- Requires internet connection

#### 4. Query Expansion ✅
- Adds synonyms to query terms
- Improves recall
- Configurable max synonyms per term
- Separate dictionaries for Bangla and English

#### 5. Named Entity Mapping ✅
- Extracts named entities from queries
- Maps entities across languages
- Pre-defined dictionary for common entities
- Easy to extend with more entities

### Retrieval Methods Implemented:

#### 1. TF-IDF ✅
- Classic information retrieval method
- Balances term frequency and rarity
- Good baseline performance

#### 2. BM25 ✅ (Recommended)
- State-of-the-art ranking function
- Better than TF-IDF
- Configurable parameters (k1, b)
- Used by major search engines

## Usage Examples

### Example 1: Basic Search

```python
from Module_B.retrieval_system import CrossLingualRetrievalSystem

# Initialize
system = CrossLingualRetrievalSystem(index_path='Module_A/document_index.pkl')

# Search
results = system.search(
    query="Bangladesh education",
    method='bm25',
    cross_lingual=True,
    top_k=10
)

# Display
system.print_results(results)
```

### Example 2: Bangla Query

```python
results = system.search(
    query="ঢাকা বিশ্ববিদ্যালয়",
    method='bm25',
    cross_lingual=True,
    expand_query=True,
    top_k=10
)
```

### Example 3: Monolingual Search

```python
# Search only in English documents
results = system.search(
    query="Bangladesh university",
    method='bm25',
    cross_lingual=False,  # Don't translate
    top_k=10
)
```

### Example 4: Custom Query Processing

```python

# Process query

    query="Bangladesh university",
    remove_stopwords=True,
    expand=True,
    translate=True,
    use_api=False
)

# Access processed queries
en_query = result['queries']['en']['query']
bn_query = result['queries']['bn']['query']
expanded_terms = result['queries']['en']['expanded_terms']
```

## Common Issues and Solutions

### Issue 1: Index File Not Found
```
Error: Index file 'document_index.pkl' not found
```
**Solution:** Run `python Module_A/indexer.py` first

### Issue 2: No Results Found
```
Found 0 documents
```
**Solutions:**
- Check if articles exist in JSON files
- Verify index was built correctly
- Try simpler query
- Disable stopword removal

### Issue 3: Translation Not Working
```
Warning: googletrans not installed
```
**Solution:** This is OK! System uses named entity mapping instead.
For better translation: `pip install googletrans==4.0.0rc1`

### Issue 4: Poor Results Quality
**Solutions:**
- Try BM25 instead of TF-IDF
- Enable query expansion
- Adjust BM25 parameters (k1, b)
- Add more named entity mappings
