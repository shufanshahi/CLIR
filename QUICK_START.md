## What is Indexing? (Module A Answer)

**Indexing** = Creating a searchable map of words → documents

```

Word "university" → [Doc 1, Doc 8, Doc 14, ...]
```

**Like:** Index at the back of a textbook

```python
query = "ঢাকা বিশ্ববিদ্যালয়"
```

### Normalization
```python
normalized = processor.normalize_query(
    "  Bangladesh   University  ",
    language='en',
    remove_stopwords=True
)
# Result: "bangladesh university"
```

### Translation
```python
# English → Bangla
translated = processor.translate_query_simple(
    "Bangladesh university",
    source_lang='en',
    target_lang='bn'

# Result: "বাংলাদেশ university"
```

### Query Expansion

## Example Usage

### Simple Search
```python
from Module_B.retrieval_system import CrossLingualRetrievalSystem

system = CrossLingualRetrievalSystem(
    index_path='Module_A/document_index.pkl'
)

# Search
results = system.search(
    query="Bangladesh university",
    method='bm25',
    cross_lingual=True,
    top_k=10
)

# Display
system.print_results(results)
```

### Custom Query Processing
```python
from Module_B.query_processor import QueryProcessor

processor = QueryProcessor()

result = processor.process_query(
    query="Bangladesh university",
    remove_stopwords=True,
    expand=True,
    translate=True
)

print(f"Detected: {result['detected_language']}")
print(f"English Query: {result['queries']['en']['query']}")
print(f"Bangla Query: {result['queries']['bn']['query']}")
```
